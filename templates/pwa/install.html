Installer sur mon téléphone

Sur iPhone ou iPad : ouvrez ce site dans Safari, puis Partager → Sur l’écran d’accueil.

Sur Android : utilisez le bouton d’installation lorsqu’il apparaît, ou le menu du navigateur → Installer l’application / Ajouter à l’écran d’accueil.

Si le Hub est déjà installé, ouvrez-le depuis son icône.
